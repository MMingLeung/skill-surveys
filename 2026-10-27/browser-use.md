## 1. 来源

- 许可：MIT（仓库 SPDX 与仓库根 `LICENSE`，版权行署名为 Gregor Zunic）。README 写明 Python 库为 MIT；托管浏览器和模型调用另计，服务条款不在本笔记范围内。

## 2. 它是什么

这是给 AI 用的开源浏览器代理库，仓库里同时放了一组 Agent Skill。2026-10-27 的 `skills/` 下有 6 个目录：`browser-use`（用命令行直接操作浏览器）、`remote-browser`（隔离的云端浏览器）、`qa`（按任务打 1 到 5 分并附证据）、`open-source`（Python 库文档路由）、`cloud`（托管 API 文档路由）、`x402`（用钱包按次付费）。`x402` 是支付脚本，和交付 SOP 无关，本笔记只确认它存在，不写步骤。

`browser_use/skills/` 是另一套东西：Python 客户端按技能 ID 向托管接口取技能并执行。它不是上面的 Markdown 技能。仓库根的 `AGENTS.md` 是库的长说明，不是技能入口。

## 3. 写法特点

- 路由型技能把「不要用我」写进 description。`open-source` 写明云 API 走 `cloud`，命令行操作浏览器走 `browser-use`。`cloud` 反过来把开源库挡在外面。宿主靠这段话分流，而不是靠目录名。
- `browser-use` 正文开头单列何时不用：公开页面、文档、接口能用普通 HTTP 读到，就不要开浏览器。需要点击、登录态、前端渲染，或直接请求只拿到空壳时，再升级到浏览器。
- 站点技能默认关闭。打开之后，要先读该站点目录里的全部文件，再自己想办法。导航返回值里可以带上该主机已有的技能文件名。
- 登录墙停下问人。密码、二次验证、授权同意、多个账号选哪个，都不自动继续。浏览器里已经登好的单点登录可以接着用。
- 一个任务维持一个工作标签页。没有人要求看画面时，不把浏览器拉到前台。任务结束关掉自己打开的、不再需要的标签；未保存的内容留着。
- 录屏默认关。用户说出记录、演示、做成视频时，当次才开。做完的任务不重演一遍来补视频。
- `qa` 的交付物是分数加证据，不是一堆截图。动手前先判断自己能不能看图；不能看图，就不假装自己看过截图。一条流程自己做，多条流程再拆开。总分取最弱的关键路径，不把坏掉的结账和好看的首页平均。评分先看任务有没有走完，再谈观感。输出第一行是分数。过不了的登录和支付就停，并写明没测到哪里。会删数据、会扣费的操作只走最小一步；做不到就说明，不硬闯。跑完关掉自己打开的隧道和云端浏览器。
- `qa` 写明测试必须走云端浏览器，不走用户本机的 Chrome。这是该技能的产品约束。
- `open-source` 和 `cloud` 的正文很短：一张「主题 → 去读哪份 reference」的表，加上几条不能看错的版本和鉴权说明。细则不写在入口。

## 4. 原理与设计意图

这组技能默认模型会为了一段公开文字就开浏览器，会在同一个 Chrome 上抢标签，会拿一张干净截图当测试通过，也会让云端浏览器一直开着计费。

「何时不用」同时管检索和成本。站点目录是为了第二次打开同一网站时不再现想选择器。`qa` 把「页面好看」和「用户要的那条路径走完」拆开，也把「模型看得见图」和「只有文字」拆开，避免盲评。三个入口互相指向，是因为库配置、云 API、直接操作浏览器若共用一段 description，会互相叫错。

## 5. 对照本库

本库的浏览器步骤在 `drission-crawler`：本机页面、站点包、登录和正式提交交给使用人。Browser Use 是另一套浏览器产品。

### 可借鉴

- `drission-crawler` 的 description 继续写清：能直接请求的页面不开浏览器；要交互、登录态或动态渲染才打开。站点差异仍先读 `references/sites/`，再写新步骤。登录、验证码、提交的停手保持原样。
- `dev-review-verify` 报告多页 DEMO 时，一条必需路径失败，整次就不算通过。这和 `qa`「总分看最弱关键路径」同向。本库结论仍是验收完成或未验收完成，不改成 1 到 5 分。
- 录屏只在使用人要求看这次过程时留下。不把做完的操作重演一遍充当证据。LIVE 仍是当次真实页面或导出文件。
- 若以后某两个技能的 description 开始互相遮盖，按这里的写法在 frontmatter 写明该用哪一个。

### 不要照搬

- 不把 `drission-crawler` 换成 CDP 助手、云端浏览器或 browser-harness。验收仍是本机回读。
- 不把「测试必须用付费云端浏览器」写进收工。本库没有这份额外依赖。
- 不把按流程并行的云端代理、计价，或 `x402` 的钱包支付写进任何技能。
- 不把 `browser-use` 技能里的标签、守护进程和点击步骤抄进站点包。站点包保持短的等待、定位、操作、回读。
- 不把按 ID 调用的托管技能客户端当成技能市场接进本库。

## 6. 一句话建议

浏览器技能在入口写清不必开浏览器，以及登录就停；站点差异留在站点包；验收看关键路径是否走通并留下当次证据。
