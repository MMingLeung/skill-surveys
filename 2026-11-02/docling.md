## 2. 它是什么

Docling 把 PDF、Office、HTML、图片等转成统一的文档对象，再导出 Markdown 或 JSON。仓库里有两层技能，不要看成一份。

使用技能在包内 `docling/.agents/skills/docling/`。入口约 80 行，按任务指向 `references/`：命令行、Python SDK、字段抽取、分块、远程服务、精简安装。抽查时 `python-sdk.md` 约 25 KB，`cli.md` 约 12 KB。

贡献者技能在仓库根 `.agents/skills/`，另有 Claude、Codex、OpenCode 的链接。`skill-router.json` 只登记三件事：评审拉取请求、写 Python、用 Pydantic AI 做代理。评审技能写明：只是读文件、不改仓库时，去用包内那份使用技能。`dignified-python` 是代码风格。`building-pydantic-ai-agents` 的 frontmatter 作者是 pydantic，属于放进仓库的第三方写法，不是文档产品本身。

2026-10-28 已读 MinerU。Docling 是另一套解析器，今天只记它的技能分层。

## 3. 写法特点

- 使用技能的 description 用使用者会说的话做触发：「这份 PDF 里有什么」「转成 markdown」「抽出表格」「读扫描件」。同时写明覆盖命令行、SDK 和远程服务。
- 入口是一张分流表：读一次用命令行，要调流水线用 SDK，只要若干字段用抽取，要检索用分块，文档很多或本机不想装模型用远程服务，想少装依赖用精简包。细则不堆在入口。
- 输出约定写成硬句。入口要求总是报告转换状态，PDF 还要报告页数。用户没指定格式时，先问要可读的 Markdown，还是要结构化 JSON。表格走表格对象的导出，不靠整篇正文碰运气。
- 坏结果有明确信号。入口写：转出来的 PDF 若近乎是空的、大段重复，或充满替换字符，多半是扫描件或复杂版面，应改用 OCR 或视觉语言模型流水线，并指向 `references/cli.md`。
- 使用技能的 `allowed-tools` 点名 `docling`、`python`、`uv`、`pip` 等命令前缀。贡献者评审技能没有这份工具清单，它要求先读 `AGENTS.md` 和路由，再按范围评审。
- 评审技能把结束条件写在每一步末尾：范围要落到具体提交，行为要有证据或写明没检查到的限度，命令和没跑的检查要记下来，结论要带上所评的提交。严重度分成三档：阻挡（安全、丢数据、支持范围内的行为错误、必跑检查失败）、建议（没有证实契约失败）、提问（缺证据，先要证据，不直接断言有缺陷）。

## 4. 原理与设计意图

模型会在没读到内容时概述一份 PDF，也会把「文件里有一些字」说成表格和阅读顺序已经对了。所以使用技能把坏输出的样子写出来，并要求带上状态和页数。

贡献者技能容易在改代码时被误用成「帮我读这份 PDF」。路由和评审技能里的交叉引用，是为了把读文档和改仓库拆开。

评审不信任字数和「检查已经过了」。入口写明：文本在不在、条目有多少，不足以证明结构正确。又写明：跳过的、还在跑的、失败的检查，都不能说成通过。`make check` 一类命令也不证明转换质量，那要另看。

远程服务是容量和依赖的出口，不是默认第一步。入口把本机一次转换放在前面。

## 5. 对照本库

本库文档交付是 `work-doc-writer` 和 `word-thesis-format`：文种模板、本地识别、打开后的预览。扫描件空文本已要求写成没识别到。

### 可借鉴

- 坏识别不只有空字符串。近空、大段重复、替换字符，同样写成没读到，并写上页范围或读到的范围。再决定用现有本地核对重试，还是停下来问人。
- 有字不等于版面对。表格、栏和阅读顺序要单独看。只有文本、没有结构证据时，手册里不把表格写成已经还原。
- `dev-review-verify` 继续把没跑的检查写成没跑。缺证据先标缺证据，不先写成某个缺陷已经坐实，也不写成通过。
- 入口保持分流。读文件和改技能、改站点包，不要靠同一次描述混在一起。

### 不要照搬

- 不把 Docling 的命令、SDK、流水线名或安装方式写进 `work-doc-writer`、`word-thesis-format`。不把文件送到 `docling-serve` 或托管服务。
- 不把「先问要 Markdown 还是 JSON」加进公文。文种仍是手册、说明书或成果报告，完成仍看模板和预览。
- 不把贡献者的 Python 风格、Pydantic AI 技能或拉取请求严重度三档写进收工。
- 不因为 `allowed-tools` 里有 `pip`、`uv`，就在交付技能里增加安装步骤。

## 6. 一句话建议

读文档时把近空、乱码和页范围写明，有字不算结构已经对；解析器仍用现有本地核对，不换 Docling。
