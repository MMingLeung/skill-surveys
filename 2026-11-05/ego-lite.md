# ego lite（把已登录浏览器交给代理）

查阅日：2026-11-05。

## 1. 来源

- 仓库：<https://github.com/citrolabs/ego-lite>
- 默认分支是 `main`。查阅以 `main` 为准，最近推送 2026-11-05。
- 星标：21750（当日 GitHub API `stargazers_count`）
- 许可：MIT（仓库 SPDX、中文 README 徽章、根目录 `LICENSE`）。README 写明 ego lite 浏览器本身是独立的免费下载，技能仓库是 MIT。
- 代理入口是 `skills/ego-browser/SKILL.md`。`plugins/ego/skills/ego-browser/` 有同名副本。frontmatter 写版本 `2.2.0`、日期 `2026-10-16`。本篇不摘安装、迁移浏览器数据和清理 Cookie 的步骤。

## 2. 它是什么

ego lite 是一个给人和代理一起用的 Chromium。中文 README 的设计是：人在自己的区域浏览，代理在单独的 Space 里操作，避免抢走当前标签。代理通过 `ego-browser` 调用页面里的一组动作，例如快照、填写、点击、等待、打开页面和截图。复杂任务由代理写成一段脚本一次执行，而不是一步一条命令。

README 写明首次启动可以迁移现有 Chrome 的登录状态、Cookie、扩展和书签，数据留在本机。目前支持 macOS 和 Windows，Linux 在路线图上。技能 description 要求凡是要用浏览器，就默认读这份技能，并优先于其他浏览器工具；范围写到了登录、填表、点击和测试。

README 自述用 31 个线上任务和另外四种浏览器工具比过速度与成功率。本篇不把这些数字当成当日复测。

## 3. 写法特点

- 技能正文很短。真正的用法不写死在仓库里，而是让代理先执行 `ego-browser skill`，再照当次输出做。输出末尾应有一行结束标记。标记不在，就表示输出被截断，要整份存成文件再分段读。原文是 “If that line is missing, the output was truncated: save it to a file and read the file in parts.”（`skills/ego-browser/SKILL.md`，MIT）。升级之后要重新要这份指南。
- 安装和清站点数据放在 `references/`，并写明何时才打开。清理前必须先读那份说明，因为有的清理会碰到整个浏览器配置，不只是当前站点。
- description 把「需要浏览器」写成默认触发，没有写能用普通请求就不打开、也没有写登录和提交交给人。版本日期停在 2026-10-16，仓库在查阅日仍有推送，所以存根和已安装的指南可能不是同一天。
- 中文 README 把页面快照当成文本模型看见页面的方式，并单独强调深层 iframe。并行 Space 是产品功能，不是技能正文里的步骤。

## 4. 原理与设计意图

作者认为别的浏览器工具要另接一个浏览器，登录态带不走，人和代理会抢同一个窗口。所以产品把登录态留在本机配置里，让代理直接用已经登录的站点。这能少碰到一些人机验证，代价是代理拿到的就是使用人的真实会话。

技能写成存根，是因为命令的旗标会随应用升级。把长指南写进 `SKILL.md` 会过期。结束标记用来发现截断：只看尾巴会漏掉前面的限制。

清理单独放一份、并且先读再动，是因为「清一下 Cookie」听起来像只影响当前站，实际可能清掉整个配置里别人的登录。

description 写得宽，是在抢「任何浏览器任务」。按技能规范，这种写法会在不该打开浏览器的请求上也被选中。

## 5. 对照本库

本库的浏览器技能是 `drission-crawler`。能直接请求的不开浏览器。登录、验证码、提交交给使用人。站点差异在站点包。ego 是另一款浏览器，并且默认继承登录态。

### 可借鉴

- 长帮助如果可能被截断，就整份落盘再读，并用一个结束标记判断有没有读完。不拿最后几行代表全文。
- 工具升级后以当次帮助为准。技能存根上的日期和已安装版本不一致时停下来对一下，不凭旧步骤继续点。
- 清理、退出登录、关浏览器这一类动作，先读它会影响的范围。范围超过当前站点就停下来问人。
- `dev-process-handoff` 写下这次用的浏览器和站点包版本。跳过的页面写明没看。

### 不要照搬

- 不安装 ego lite，不迁移 Chrome 配置，不把 `ego-browser` 写成 `drission-crawler` 的入口。
- 不把「要用浏览器就默认打开」写进 description。能请求的仍不打开。
- 不让代理登录、继承 Cookie 或代为提交。使用人的登录态不交给代理。
- 不把多 Space 并行、自动沉淀工作流或 README 里的速度数字写进站点包。
- 不把清理整个浏览器配置当成失败后的重试。失败仍落盘，同一原因不原样再点。

## 6. 一句话建议

长输出要读完，清理前要看清范围；本库仍用 DrissionPage 和站点包，不把已登录浏览器交给代理。
