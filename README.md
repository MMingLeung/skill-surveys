# skill-surveys

按日记录公开高星 Agent Skills 的阅读笔记。本仓库只放笔记，不是可安装技能，没有 `skills/` 目录，也不提供交付流程。

笔记里的「本库」指另行维护的交付技能仓库 [MMingLeung/agent-skills](https://github.com/MMingLeung/agent-skills)。对照写在笔记里，不把那边的技能搬到这里，也不改那个仓库。

约定：

- 按日建目录 `YYYY-MM-DD/`。
- 每个被读仓库一篇笔记，文件名用仓库简称。
- 同日另写 `synthesis.md`，汇总写法、设计意图，以及对照交付型技能可参考与不宜搬入的地方。
- 跨日仍然成立的判断写在仓库根下的 [`insights.md`](insights.md)，单日细节不重复堆进该文件。
- 星标取笔记所写日期的 GitHub API `stargazers_count`。数字会变，不回写历史。
- 专有或未明确开源的正文不摘录步骤、脚本和长段原文。
