# agnix（代理配置检查）

查阅日：2026-11-06。

## 1. 来源

- 仓库：<https://github.com/agent-sh/agnix>
- 默认分支是 `main`。查阅以 `main` 为准。
- 星标：471（当日 GitHub API `stargazers_count`）
- 许可：README 与仓库文件是 MIT OR Apache-2.0（同时有 `LICENSE-MIT` 与 `LICENSE-APACHE`）。当日 GitHub API 的 SPDX 只标了 Apache-2.0。笔记按双许可理解，不摘规则正文。
- 技能入口是 `skills/agnix/SKILL.md`，很短，负责调用命令行检查器。规则本体在 `knowledge-base/rules.json`，说明在 `knowledge-base/VALIDATION-RULES.md`，两边不一致时持续集成会失败。语言服务和 MCP 服务是检查器的另外两种入口。README 写的规则规模是数百条，本笔记不把这个条数当成当日复测。

## 2. 它是什么

这是检查代理配置会不会被宿主静默忽略的工具。它看 `CLAUDE.md`、`AGENTS.md`、`SKILL.md`、钩子、MCP，以及 Cursor 规则等文件的字段和常见坏写法。编辑器插件和持续集成动作可以在提交前跑同一套检查。

技能本身不做规则研究。它先看命令在不在，再对使用人指出的目录做检查。只有使用人要求修改时才应用修复，然后把检查再跑一遍，确认还剩什么。否则不改文件。预览模式只展示会改什么。

## 3. 写法特点

- description 用使用人会说的话作触发：检查技能、检查说明文件、检查钩子、检查 MCP。
- 修复分档。默认修复只动高把握的项。更宽的一档会带上中等和低把握的修改。`AGENTS.md` 把把握分成高、中、低三档。低把握的改动不是默认行为。
- 技能列出的常见问题都是格式和触发，不是任务对错：名字必须小写加连字符，目录名要和 `name` 一致，description 里要有何时使用，模型本来就会的空话（例如只写「要准确」）应当删掉。
- 可以按宿主缩小规则集。README 的维护优先级里，Cursor 排在较后的一档，排在 Claude Code、Codex 等有原生约定的工具后面。因此它的 Cursor 规则不能当成所有宿主的同一套契约。
- 单条规则可以用说明命令查看依据。依据来自规范、论文和真实损坏案例，写在知识库里，不写在技能正文里。
- 仓库自己的完成定义是：有测试覆盖才算做完。本地预检缺了工具就失败，而不是悄悄跳过。预检不能代替托管的多系统持续集成。规则表和生成物要一起改，计数对不上就停。

## 4. 原理与设计意图

技能文件差一个字段，宿主会直接不加载，模型仍会继续做事，看起来像「没遵守技能」。作者认为这种静默失败比明显报错更难发现，所以用检查器在运行前抓住名字、触发句和结构问题。

自动修复默认收窄，是因为低把握的改写会把还能用的说明改坏。再跑一遍，是为了区分「已修好」和「修完仍有错误」。

它检查的是配置能不能被看见，不是代理这次有没有把页面打开、把文件交出去。格式通过和任务通过是两件事。

## 5. 对照本库

本库用 `evals.json` 看会不会叫错，用 `dev-review-verify` 看当次产物。这份仓库对得上的是：description 要有何时使用，名字和目录一致，模型已经会的句子不必再写。

### 可借鉴

- 各技能 description 保持「何时用、何时不用」。负例指向该归的那个已有技能，而不是另起名字。
- `dev-review-verify` 若以后要看技能说明是否仍和正文是同一件事，那只是触发面的检查。通过了也不写成验收完成。必需路径仍要打开当次页面、导出文件或窗口。
- `dev-process-handoff` 在改了触发句或停手条件时写明，便于下一次对上 description。不把检查器的告警清单当成交接正文。

### 不要照搬

- 不安装 agnix，不把它的自动修复跑在 `MMingLeung/agent-skills` 上。低把握改写尤其不要无人值守。
- 不把规则条数、格式告警或「技能能被加载」写成 LIVE 的替代。`evals.json` 仍是触发样本，收工仍看产物。
- 不按它的 Cursor 规则改写 `drission-crawler`、`government-service-design` 或政务界面。那一档在来源里不是优先维护的宿主约定。
- 笔记仓库没有 `skills/` 目录。不在这里加可安装技能，也不加钩子配置去「通过」这套检查。

## 6. 一句话建议

配置检查只能说明技能文件有机会被加载；本库仍用触发样本和当次产物验收，不安装这套检查器，也不自动改写现有技能。
